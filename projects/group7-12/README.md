# SLA_Project_7-12
Project Description
This project builds an interactive computer simulation of the Yasti Yantra. The user can:

Move a virtual Sun across the sky using a time or altitude slider.
Rotate a virtual staff toward it and watch the plumb line shift along the scale.
See the measured angle and computed values (altitude, time of day, latitude) update live.
Compare the simulated reading with the exact astronomical value to see accuracy.
