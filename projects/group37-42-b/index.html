About The Project

Dhanur Yantra is a simple robotic project that aims and shoots a small bow automatically using motors and basic electronic controls.

Main Features

  • Automatic aim control (Up/Down and Left/Right).
  • Electronic trigger button for firing.
  • Simple battery-powered system.

Component / ParameterSpecification

Actuators2x SG90 / MG996R Servo Motors (Pan/Tilt)
Operating Voltage5V to 6V DC
Trigger Mechanism5V Single-Channel Relay / Solenoid Actuator

How It Works

  1. Turn on the power switch.
  2. Motors move the bow to point at the target.
  3. The string is pulled back and held in place.
  4. Press the trigger button to release the bowstring.
